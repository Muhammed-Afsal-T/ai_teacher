# AI Teacher 🎓🎙️

An advanced, voice-first AI English teacher built with **Native Android (Kotlin + Jetpack Compose)** and a **Python FastAPI backend**.

The app is specifically designed for Malayalam native speakers, featuring full understanding of Malayalam speech, push-to-talk voice interactions, emotional voice modulation, real-time patience tracking, animated grammar diffs, and scheduled daily reminders.

---

## 🌟 Key Features & Strict Behavioral Rules

### 1. The 3 Behavioral Rules
- **Rule 1 (Genuine Doubts in Malayalam)**:
  - If the user speaks Malayalam to ask a genuine doubt or clarification (e.g., *"ഇതിന്റെ അർത്ഥം എന്താണ്?"*, *"How do I say this in English?"*), the AI responds warmly, explains the concept thoroughly in Malayalam, and then encourages the student to continue in English.
  - **Patience Penalty**: 0 or +2 (No penalty for genuine curiosity).
- **Rule 2 (Casual Malayalam = Pure Anger)**:
  - If the user uses Malayalam for casual conversation, answers general questions in Malayalam, or is being lazy instead of attempting English, the AI **hates this**.
  - The AI gets visibly angry, scolds the user in English, and drops its Patience Score significantly (-20 to -35 points).
- **Rule 3 (Strict English Grammar Corrections)**:
  - If the user makes English grammatical, tense, or preposition errors, the AI strictly identifies the mistake, explains the correction, and presents an animated **Error Diff Card** (Strikethrough Red for the mistake, Bold Green for the correction).

### 2. Emotional Voice Modulation (SSML + Edge TTS)
- **High Patience (>70)**: Warm, encouraging, calm pitch and standard rate (`rate="0%"`, `pitch="+2Hz"`).
- **Medium Patience (30-70)**: Firm, serious, brisk intonation (`rate="+10%"`, `pitch="+3Hz"`).
- **Low Patience (<30)**: Sharp, furious, cutting pitch with strong emphasis (`<emphasis level="strong">`).
- **LIFO Tag Stack Parser**: Ensures malformed or crossed SSML tags generated by LLMs are properly nested and closed before synthesis.

### 3. Database Persistence (SQLite)
Exact 4-table schema:
- `user_profile`: Tracks student level, patience score (0-100), streak count, and last active date.
- `curriculum_vault`: Pre-seeded conversational prompts and targets for levels A1 through B2.
- `error_ledger`: Automatically records grammar mistakes and increments `recurrence_count` for repeated errors.
- `session_history`: Historical logs of fluency, grammar scores, and penalties applied.

### 4. Push-To-Talk & Nightly Notifications
- **Microphone Button**: Implemented using Jetpack Compose `pointerInput` with `tryAwaitRelease()` (avoiding invalid `detectTapGestures` `onRelease`). Features pulsating multi-ring ripple animations while held down.
- **Nightly 9:30 PM Reminder**: Scheduled via `AlarmManager.setExactAndAllowWhileIdle()` targeting 21:30 daily, with Android 13+ `POST_NOTIFICATIONS` runtime permission support.

## 🚀 Quick Start Guide

### 1. Python Backend Setup

```powershell
cd backend

# 1. Create and activate virtual environment
python -m venv .venv
.\.venv\Scripts\Activate.ps1

# 2. Install dependencies
pip install -r requirements.txt

# 3. Configure your Groq API key in .env
# Edit backend/.env and set:
# GROQ_API_KEY=gsk_...

# 4. Start the backend server
python run.py
```
- API Docs: `http://localhost:8000/docs`
- Health Check: `http://localhost:8000/api/v1/health`

### 2. Android CLI Build & Run

You can build the app completely from the command line without opening Android Studio!

```powershell
# From the project root:
cd c:\Users\DELL\Downloads\Ai-teacher

# Ensure the Gradle wrapper is initialized:
powershell -ExecutionPolicy Bypass -File scripts\setup_gradle_wrapper.ps1

# Build the Debug APK:
.\gradlew.bat assembleDebug

# Install on a connected device/emulator:
.\gradlew.bat installDebug
```

The compiled APK will be generated at:
`app/build/outputs/apk/debug/app-debug.apk`

## 🧪 Running Automated Tests

### Backend Unit Tests
```powershell
cd backend
.\.venv\Scripts\python -m unittest discover -s tests
```
Verifies:
- LIFO SSML Tag Stack Parser (proper nesting, auto-closing dangling tags, stripping unsupported tags).
- SQLite Database Operations (CRUD on `user_profile`, `error_ledger` recurrence counts, `session_history`).
